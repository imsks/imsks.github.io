⚠ If Research Sessions Drop 20% — The 24-Hour Diagnosis
Three checks in order. Never start with product quality.
01
Rule out external cause first
Check: Did a major election result drop last week, creating a spike that inflated the baseline?

Check: Is there a national news event pulling attention away from political research?

Check: Did a social media post misrepresent Rajniti, causing distrust?

If yes to any → context explains the drop. Communicate to co-founder, monitor for normalisation.
02
Separate acquisition from engagement
Check: Did new user volume also drop this week?

If yes → acquisition problem. Fewer users arrived = fewer sessions. Fix: GTM channel review, TBE community reactivation.

If no → same users, fewer sessions. This is a retention or engagement problem. Product is failing to bring existing users back. Proceed to Check 3.
03
Find the funnel breakpoint
Check: Where in the funnel did users stop?

Visits → Profile drop ↑ = search/navigation broken
Profile → 60s drop ↑ = content quality issue
60s → Upgrade drop ↑ = paywall friction

Then — and only then — check data accuracy, AI summary quality, and missing politician profiles.
