# Sachin Shukla — AI Product Manager Portfolio

Live at **https://imsks.github.io**

A complete product case study for **Rajniti**, an AI civic-research tool for India's 970M voters — plus the supporting PM craft artifacts (prioritisation, OKRs, stakeholder management, user research, experimentation, analytics).

## Structure
- `index.html` — portfolio landing page
- `rajniti_chapter2_market_opportunity.html` — Market Opportunity (TAM/SAM/SOM, competition, pricing)
- `rajniti_roadmap.html` — Roadmap & Prioritisation (Now/Next/Later)
- `rajniti_chapter4_trust_safety.html` — Trust & Safety framework (responsible AI)
- `rajniti_market_sizing.html` — Bottom-up market sizing model
- `rajniti_rice_prioritization.html` — RICE + Kano feature scoring
- `rajniti_okrs_dashboard.html` — Q1 OKRs + north-star dashboard
- `rajniti_stakeholder_map.html` — Stakeholder map + RACI
- `rajniti_interview_script.html` — JTBD user interview script
- `rajniti_experiment_brief.html` — A/B test design (the Blur Test)
- `rajniti_analytics_dashboard.html` — PM analytics dashboard
- `Sachin_Shukla_AI_PM_Resume.pdf` — resume
